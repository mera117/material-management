# Material Management UI

Aplicación web desarrollada con Angular para la administración de materiales.

## Tecnologías

* Angular 20
* TypeScript
* SCSS
* Reactive Forms
* HttpClient

## Funcionalidades

### Gestión de Materiales

* Registro de materiales
* Actualización de materiales
* Consulta de materiales
* Filtros por tipo
* Filtros por ciudad

### Catálogos

* Departamentos
* Ciudades
* Tipos de Material
* Estados

## Estructura

```text
src/app

core
 └── services

models

pages
 └── materiales

app.routes.ts
app.config.ts
```

## Configuración

Backend:

```text
http://localhost:8081
```

Frontend:

```text
http://localhost:4201
```

## Instalación

Instalar dependencias:

```bash
npm install
```

Ejecutar aplicación:

```bash
ng serve --port 4201
```

## Funcionalidades de la Interfaz

* Formulario de registro
* Edición de materiales
* Tabla de resultados
* Filtros de búsqueda
* Validaciones de formulario
* Diseño responsive
